## Technical boundaries
- Use Astro + TypeScript with STATIC output for Cloudflare Pages. Do not introduce server-side rendering or a large client-side framework without a genuine requirement.
- Centralise tokens, data and reusable components. No giant copy-and-pasted page components.
- Default interactivity to browser-native elements; prefer accessible details/summary for FAQs.
- Use semantic HTML, meaningful alt text, keyboard support, visible focus and responsive images.
- All content and links must resolve; no href='#', pseudo-buttons or TODO copy on completed pages.
- Add dependencies only as needed.
- Use Node 24. Run npm install, npm run check and npm run build. Commit a package-lock.json generated by npm.
- Update docs/IMPLEMENTATION_LOG.md as you work.
